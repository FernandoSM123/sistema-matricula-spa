Decisiones
  • El código de error va primero en los filtros, porque es lo que busca el administrador cuando alguien reporta un error. Acepta el código completo o sus 32 caracteres.
  • El origen Peticion se muestra como "Solicitud". Sin usuario, el rol se muestra como "Sin sesión". Los errores de correo no tienen método ni ruta.
  • La lista no trae el detalle técnico: se ve en V-38. Los errores no se marcan como revisados ni se eliminan (§1.3).
